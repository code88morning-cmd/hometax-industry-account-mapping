# Hometax Industry Account Mapping Sample

사업자등록 업종 정보를 활용해 홈택스 장부 작성 단계에서 계정과목 후보를 추천하는 기능의 설계 샘플입니다.

## 포함 자료

- `data/industry-code-sample.csv`: 데모용 업종 정보
- `data/account-code-sample.csv`: 데모용 계정과목 코드
- `data/industry-account-mapping-sample.csv`: 업종/거래유형/추천 계정과목 매핑
- `docs/recommendation-rule.md`: 추천 규칙 문서
- `examples/input-example.json`: API 요청 예시
- `examples/output-example.json`: API 응답 예시
- `preview/preview.html`: 브라우저 미리보기 화면

## 주의

이 자료는 개발 설계용 샘플입니다. 실제 홈택스 업종코드, 세법상 계정과목 판단, 세무 신고 기준을 대체하지 않습니다.
