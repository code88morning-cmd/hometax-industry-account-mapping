# 추천 규칙 샘플

## 1. 목적

사업자등록 단계에서 확보된 업종 정보와 장부 입력 단계의 거래 내용을 연결하여 계정과목 후보를 제안한다.

## 2. 입력값

- 업종코드
- 업태
- 종목
- 거래일자
- 거래금액
- 거래내용
- 결제수단

## 3. 추천 점수 산정 예시

```text
추천점수 = 업종 일치 점수 + 거래 키워드 점수 + 거래유형 점수 - 예외 위험 점수
```

| 항목 | 예시 점수 |
|---|---:|
| 업종코드 일치 | +0.40 |
| 거래 키워드 일치 | +0.35 |
| 거래유형 일치 | +0.20 |
| 예외 가능성 존재 | -0.10 |

## 4. 추천 등급

| 점수 | 등급 | 의미 |
|---:|---|---|
| 0.85 이상 | 높음 | 1순위 추천 |
| 0.70 이상 | 보통 | 후보 추천 |
| 0.70 미만 | 낮음 | 참고 후보 또는 미추천 |

## 5. 예외처리

- 같은 거래가 둘 이상의 계정과목에 해당할 수 있으면 복수 후보로 표시한다.
- 확신도가 낮으면 사용자가 직접 선택하도록 안내한다.
- 세무 신고 판단을 대체하지 않으며, 필요 시 세무 전문가 확인 문구를 표시한다.

## 6. 화면 안내 문구

> 추천 계정과목은 업종 정보와 거래내용을 기반으로 한 참고 후보입니다. 실제 장부 작성과 신고 시 거래 실질에 따라 달라질 수 있습니다.
