# Recommendation Rule

## 목적
사업자등록 업종 정보와 거래내용을 연결하여 홈택스 장부 입력 단계에서 계정과목 후보를 추천한다.

## 추천 기준
- 업종 일치 점수
- 거래 키워드 점수
- 거래 유형 점수
- 예외 위험 점수

## 예외 처리
- 동일 거래가 둘 이상의 계정과목에 해당하면 복수 후보를 제시한다.
- 점수가 낮으면 자동 선택하지 않고 사용자가 직접 판단하도록 유도한다.
- 세무 신고 판단을 대체하지 않으며, 필요 시 세무 전문가 확인 문구를 표시한다.

## 주의
본 추천 결과는 장부 입력 보조 기능이며 세무 신고 판단을 대체하지 않는다.
